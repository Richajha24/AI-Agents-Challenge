# Agent 20 — Consultant Agent

## Overview

Consultant Agent is an AI-powered business strategy assistant that analyzes business challenges and generates structured consulting-style recommendations.

The agent mimics the workflow of management consultants by evaluating problems, identifying risks, and proposing actionable solutions.

---

## Features

### Business Analysis
- Problem assessment
- Root cause identification
- Strategic evaluation

### SWOT Analysis
- Strengths
- Weaknesses
- Opportunities
- Threats

### Recommendation Engine
- Strategic actions
- Operational improvements
- Growth opportunities

### Action Planning
- Priority roadmap
- Implementation steps
- Success metrics
