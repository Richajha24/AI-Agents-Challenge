# Agent 18 — Content Factory

## Overview

Content Factory is a Streamlit-powered AI content creation platform that generates blogs, social posts, marketing copy, newsletters, and long-form content.

It helps creators, startups, and marketers scale content production.

---

## Features

### Content Generation
- Blog posts
- LinkedIn posts
- Twitter/X content
- Marketing copy
- Newsletter content

### Tone Control
- Professional
- Casual
- Educational
- Promotional

### Audience Targeting
- Startups
- Developers
- Students
- Businesses

### Download Support
- Markdown output
- Copy-ready content

---
