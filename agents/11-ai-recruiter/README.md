# AI Recruiter Agent

## Overview

AI Recruiter acts as an intelligent hiring assistant.

It compares resumes against job descriptions and evaluates candidate suitability.

---

## Core Features

### Resume Analysis

* Skill Extraction
* Experience Analysis
* Education Analysis

### Candidate Evaluation

* Match Percentage
* Strengths
* Weaknesses

### Hiring Recommendations

* Interview Recommendation
* Missing Skills
* Improvement Suggestions

---

## Input

Resume PDF

Job Description Text

---

## Output

* Match Score
* Skill Analysis
* Missing Skills
* Interview Recommendation
* Improvement Roadmap

---

## Tech Stack

* Python 3.12
* Groq API
* PyPDF2
* Rich
* python-dotenv

CLI only.

No frontend.

No database.
