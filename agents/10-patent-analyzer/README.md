# Patent Analyzer Agent

## Overview

Patent Analyzer evaluates patents and extracts technical and business insights.

The goal is to help founders, researchers, and investors understand innovation opportunities.

---

## Core Features

### Patent Understanding

* Patent Summary
* Technical Breakdown
* Core Innovation

### Commercial Analysis

* Market Potential
* Competitive Advantages
* Monetization Opportunities

### Innovation Evaluation

* Novelty Assessment
* Scalability Analysis
* Practicality Score

---

## Input

Patent PDF or patent text.

---

## Output

* Patent Summary
* Innovation Analysis
* Market Potential
* Commercial Opportunities
* Risk Assessment

---

## Tech Stack

* Python 3.12
* Groq API
* PyPDF2
* Rich
* python-dotenv

CLI only.

No frontend.

No database.
