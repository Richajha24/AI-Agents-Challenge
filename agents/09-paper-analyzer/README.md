# Research Paper Analyzer Agent

## Overview

Research Paper Analyzer helps students and researchers quickly understand academic papers.

It extracts insights, explains methodologies, and generates presentation-ready summaries.

---

## Core Features

### Paper Understanding

* Abstract Summary
* Methodology Explanation
* Results Analysis

### Research Insights

* Strengths
* Weaknesses
* Limitations
* Future Work

### Presentation Support

* Viva Preparation
* Key Questions
* Presentation Notes

---

## Input

Research Paper PDF.

---

## Output

* Executive Summary
* Key Findings
* Methodology Breakdown
* Limitations
* Future Scope
* Presentation Notes

---

## Tech Stack

* Python 3.12
* Groq API
* PyPDF2
* Rich
* python-dotenv

CLI only.

No frontend.

No database.
